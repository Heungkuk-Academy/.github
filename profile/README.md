# Heungkuk-Academy

흥국생명 연수원 예약 관리 시스템을 구성하는 레포지토리 모음입니다.

## 레포지토리

| 레포 | 설명 |
|---|---|
| [academy-backend](https://github.com/Heungkuk-Academy/academy-backend) | API 서버 |
| [academy-frontend](https://github.com/Heungkuk-Academy/academy-frontend) | 웹 프론트엔드 |
| [academy-infra](https://github.com/Heungkuk-Academy/academy-infra) | 배포 설정 |
| [academy-docs](https://github.com/Heungkuk-Academy/academy-docs) | 문서 |

## 작업 규칙

1. 이슈 생성 (Feature / Bug / Chore 템플릿 사용)
2. `develop`에서 작업 브랜치 분기 (`feat/…`, `fix/…`, `docs/…`, `chore/…`)
3. PR 생성 후 리뷰, 머지
4. 릴리스는 `develop` → `main` PR

`main`에는 직접 커밋하지 않습니다.

## 커밋 메시지


| type | 용도 |
|---|---|
| `feat` | 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서 |
| `chore` | 설정, 빌드, 기타 |
| `refactor` | 구조 개선 |
| `test` | 테스트 |
